1. users — гравці
----------------------------------------------------------------
Поле          Тип           Опис
-----------   -----------   ------------------------------------
id            INT (PK)      Унікальний ідентифікатор
username      VARCHAR       Нікнейм гравця
email         VARCHAR       Email (унікальний)
created_at    TIMESTAMP     Дата реєстрації

Зв'язки:
  -> gardens        (один до багатьох)
  -> achievements   (один до багатьох)


----------------------------------------------------------------
2. gardens — сади гравця
----------------------------------------------------------------
Поле          Тип           Опис
-----------   -----------   ------------------------------------
id            INT (PK)      Унікальний ідентифікатор
user_id       INT (FK)      Посилання на users.id
name          VARCHAR       Назва саду (наприклад "Мій перший сад")
width_cells   INT           Ширина сітки (кількість клітинок)
height_cells  INT           Висота сітки (кількість клітинок)
created_at    TIMESTAMP     Дата створення

Зв'язки:
  -> plant_instances  (один до багатьох)
  -> weather_events   (один до багатьох)

----------------------------------------------------------------
3. plants — довідник видів рослин
----------------------------------------------------------------
Поле          Тип           Опис
-----------   -----------   ------------------------------------
id            INT (PK)      Унікальний ідентифікатор
name          VARCHAR       Назва (наприклад "Помідор")
species       VARCHAR       Вид / сорт
growth_days   INT           Кількість ігрових днів до повного росту
climate_type  VARCHAR       Тип клімату (помірний / тропічний / посушливий)
icon_key      VARCHAR       Ключ іконки у клієнтському застосунку

Зв'язки:
  -> plant_instances  (один до багатьох)

----------------------------------------------------------------
4. plant_instances — конкретна рослина в саду
----------------------------------------------------------------
Поле           Тип           Опис
------------   -----------   ------------------------------------
id             INT (PK)      Унікальний ідентифікатор
garden_id      INT (FK)      Посилання на gardens.id
plant_id       INT (FK)      Посилання на plants.id
cell_x         INT           Координата X на сітці саду
cell_y         INT           Координата Y на сітці саду
planted_at     DATE          Ігрова дата посадки
growth_stage   INT           Поточна стадія росту (0 — насіння, max — зрілість)
is_watered     BOOLEAN       Чи полита сьогодні
is_fertilized  BOOLEAN       Чи удобрена

Зв'язки:
  -> tasks  (один до багатьох)

Обмеження:
  UNIQUE (garden_id, cell_x, cell_y) — одна рослина на клітинку

----------------------------------------------------------------
5. tasks — завдання по догляду за рослиною
----------------------------------------------------------------
Поле               Тип           Опис
----------------   -----------   ------------------------------------
id                 INT (PK)      Унікальний ідентифікатор
plant_instance_id  INT (FK)      Посилання на plant_instances.id
task_type          VARCHAR       Тип завдання: water / fertilize / harvest / prune
due_at             TIMESTAMP     Ігровий дедлайн виконання
is_done            BOOLEAN       Чи виконано завдання

----------------------------------------------------------------
6. weather_events — погодні події в саду
----------------------------------------------------------------
Поле          Тип           Опис

event_type    VARCHAR       Тип події: rain / drought / frost / heatwave / storm
intensity     INT           Інтенсивність (1–10)
occurred_at   TIMESTAMP     Коли відбулась подія
